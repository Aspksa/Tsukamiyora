# Tsukamiyora Chat v0.4.0 — initial integration

Запустите Tsukamiyora и откройте **http://127.0.0.1:4177/chat**. Перед использованием включите Cloud.ru, задайте ключ и выберите модель в **/settings**.

- `POST /api/chat/stream` принимает `{"conversationId":"chat-1","messageId":"unique-1","message":"Привет"}` и возвращает `text/event-stream` с событиями `delta`, `done` или `error`.
- Перед генерацией сервер выбирает до 10 сообщений текущего диалога и до 4 релевантных фрагментов из локального RAG. Сообщения других диалогов исключаются из контекста; общая библиотека остаётся общей.
- Суммарный текст запроса ограничивается приблизительно 12 000 символов; `max_tokens=1024` ограничивает длину ответа. Это ограничение затрат, но **не точный подсчёт токенов и не денежный лимит**.
- При успешном завершении потока сообщение пользователя и ответ сохраняются в локальной SQLite-памяти. При ошибке потока незавершённый ответ не сохраняется.
- Идентификатор сообщения предотвращает повторную отправку уже сохранённого сообщения. Во время одновременных запросов с одинаковым ID дедупликация не гарантирована.
- `GET /api/metrics` включает статистику чата. Реальный расход токенов и стоимость пока не рассчитываются.
- Страница чата показывает ответ по мере поступления. Идентификатор диалога хранится в sessionStorage браузера.

**Безопасность и ограничения:** локальный HTTP API не имеет полноценной авторизации; не публикуйте порт в сети. Сведения из документов считаются недоверенными данными, но защита от prompt injection пока не исчерпывающая. Автоматическая генерация, streaming и сохранение чата реализованы как начальная интеграция; успешное подключение к реальному аккаунту Cloud.ru и CI должны быть проверены отдельно. Кеширование ответов не включено, чтобы избежать возврата устаревших или чужих данных.
