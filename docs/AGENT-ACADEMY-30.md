# Академия 30 агентов

Реестр координатора содержит 30 специализированных ролей. Это регистрация ролей, а не запуск 30 языковых моделей или полноценных исполнителей.

## Реализовано

- SQLite таблица `agent_training`: роль, навык, задача, оценка 0–1, проходной балл 0.8, свидетельство результата и время.
- Индивидуальные профили и история обучения. Уровни 1–5 рассчитываются по числу тренировок и средней оценке; они не подтверждают общую компетентность вне проверенных задач.
- `agent_skill_candidates`: версии предложенных навыков, начальный статус `pending`; автоматическое применение отсутствует.
- API `GET /api/rag/agents/academy/profiles`, `GET /api/rag/agents/academy/profile/:role`, `GET /api/rag/agents/academy/history/:role`, `POST /api/rag/agents/academy/results`, `GET/POST /api/rag/agents/academy/candidates`.
- Блок «Академия 30 агентов» на странице знаний.

## Ограничения и дальнейшая работа

Результаты тренировок сохраняются серверным оценщиком: публичный API произвольной самооценки удалён. Для шести базовых ролей доступны простые детерминированные экзамены через `GET /api/rag/agents/academy/exams` и `POST /api/rag/agents/academy/exams/grade` с полями `role` и `answers` (массив индексов ответов). Это учебная проверка, не независимая оценка реальных навыков: ответы к статическим экзаменам доступны в исходном коде, и повторные прохождения пока могут повышать уровень. До подключения доверенного тестового движка уровни отражают только сохранённые оценки. Нужны: безопасный диспетчер реальных инструментов для каждой роли, проверяемые тестовые наборы, независимые экзамены, расписание тренировок, изоляция опасных операций, правила продвижения версий и отката. Никаких автоматических изменений кода, ключей или критических данных на основании самооценки агентов.

## Реальные локальные практические проверки

`GET /api/rag/agents/academy/practice` перечисляет три проверяемые задачи, а `POST /api/rag/agents/academy/practice/:role` запускает соответствующую проверку на сервере. Роли: `rag_evaluator` (метрики RAG), `diagnostician` (детектор ошибок), `cloud_economist` (лимиты Cloud.ru). Они вызывают существующие локальные функции, не отправляют запросы в Cloud.ru и не меняют настройки.

Фиксированные задания с префиксами `practice:` и `academy:` учитываются в прогрессе лишь один раз на роль и ключ задачи. Повтор возвращает ранее сохранённый результат. Это предотвращает простую накрутку, но не делает упражнения независимыми: наборы тестов статические и покрывают только три роли. Нужны независимые сценарии на меняющихся данных, доверенный планировщик, проверка регрессий и настоящие безопасные исполнители остальных ролей.

## Фоновый планировщик обучения

Модуль `src/agent-training-scheduler.js` запускается после старта локального сервера и проверяет доступные локальные упражнения каждые 6 часов. `GET /api/rag/agents/academy/scheduler` показывает статус, `POST /api/rag/agents/academy/scheduler/run` выполняет проверку вручную. При штатном завершении сервера таймер останавливается. Повторные фиксированные упражнения пропускаются, ошибки отдельных упражнений не останавливают цикл.

Это не непрерывное самообучение: пока доступны три ограниченных тестовых задания, которые выполняются один раз для каждого ключа. Для полноценного роста нужны новые независимые задания, безопасные инструменты по ролям и измерение качества на реальных задачах. Запуск CI и Windows-тестов следует проверить после слияния.

## Расширение практики и планы развития

Локальная практика теперь включает восемь ролей: `rag_evaluator`, `diagnostician`, `cloud_economist`, `security_engineer`, `index_engineer`, `quality_controller`, `tester`, `performance_analyst`. Пять новых проверок охватывают редактирование секретов в учебном тексте, SHA-256, сравнение метрик качества, простые программные утверждения и агрегацию задержки. Это детерминированные проверки локальных функций, а не полноценные автономные исполнители или доказательство профессиональной компетентности.

`GET /api/rag/agents/academy/development` показывает планы развития всех 30 ролей, а `GET /api/rag/agents/academy/development/:role` — конкретного агента. Слабые навыки определяются из сохранённых оценок. Планы требуют независимых тестов; автоматическое повышение версий отключено.

Фоновый планировщик выполняет восемь практик при первом запуске, затем проверяет наличие новых заданий раз в шесть часов. Повтор одного и того же задания не повышает уровень. Для действительно непрерывного роста необходимы версионируемые независимые наборы задач и измеримые результаты на реальных входных данных.
